# 数据归属与命令行会话恢复

| 事实 | 写入位置 | 谁使用它 |
| --- | --- | --- |
| 主人事项与操作记录 | `human_items`、`human_item_activity` | 待我处理、项目行动、周回顾、撤销 |
| 工作目录、暂停原因 | `cells` | 调度、目录协作、项目和分身实况 |
| 消息及认领状态 | 收件箱 | 定时提醒、事件处理、是否可撤销 |
| 可读产物 | 带版本的共享文档 | 主人修订、决定校验、报告阅读 |
| 工作交接与材料 | `working_note`、`reference` | 项目白板、按需查阅和检索 |
| 工作过程 | 按分身排序的证据记录 | 时间线、项目核查、命令行会话续接 |

命令行会话是现有证据的一种执行方式。恢复时按持久游标补上新消息和记录。工作目录、会话和前缀身份决定能否沿用已有上下文。需要重新建立会话时，保留原任务、最近摘要、引用和动态尾部；已接纳的纠偏消息只在实际送达后确认。

同一组领域操作供 Web 与外部主代理调用。读操作生成投影，写操作校验调用者和所见版本，提交事务后才通知界面刷新。角色选择、业务状态键与工具权限由预设层提供给内核，通用执行层保持对产品身份和文案的独立性。

回归入口见[上下文装配](../../packages/context/test/hydrate.test.ts)、[命令行续接](../../packages/loop/test/cli-followup.test.ts)、[受限写入](../../packages/loop/test/tools.test.ts)与[项目行动记录](../../presets/test/project-books.test.ts)。
