# 待我处理与可定制决定

主人看到一个按事项组织的收件箱。需要做的事和需要决定的事可以筛选。项目行、提醒和深链使用同一个事项编号。需要主人处理同一件事时，在所属分身的主题范围内更新原卡，其他分身可以独立使用相同的主题名称。

| 操作 | 读写约定 |
| --- | --- |
| 回答或完成人工行动 | 使用卡片给出的选项和输入字段，附 `seenItemRevision`。有文稿的决定同时校验主人实际看过的 `seenArtifactVersion`。 |
| 同步修改 | 新卡到达保持当前事项和输入内容。已打开的卡或草稿发生变动时，提示复核再提交。 |
| 编辑方案 | 保存时携带方案版本。冲突后展示远端最新内容，保留本地修改供比较。 |
| 延后或恢复 | 延后只影响显示时间。处理记录保存撤销所需的修订与回执，已被后台认领的决定需要根据真实执行情况更正。 |
| 中止并重新打开项目 | 受影响项目以标题逐个确认，重开在相应轮次的后台清理完成后执行。 |

工作台的操作记录可撤销符合条件的决定。总览读取同一组事项，外部主代理用 `list_human_items` / `decide_human_item`，并把实际看到的选项和版本一并传回。

回归入口见[事项领域命令](../../packages/cell/test/human-items.test.ts)、[真实 HTTP 接口](../../apps/gtd-desk/test/api.test.ts)与[收件箱交互](../../apps/gtd-desk/test/human-inbox-browser.test.ts)。
