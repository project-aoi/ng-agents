# 宿主与权限边界

**`P-SAFE-1`**　工作目录来自真实宿主。程序仅回收自建且能够确认归属的资源。严禁递归删除用户提供的目录或修改用户主目录配置。

**`P-SAFE-2`**　内核发布当前活跃目录及占用它的任务。协调器根据工作性质分派查阅、续派原分身或单独安排 Git 工作树。

**`P-SAFE-3`**　动手前检查目录、分支和工作树。遇到陌生修改或进行中的合并、变基，停手报告并等待。保留主人未提交的内容。

**`P-SAFE-4`**　子节点权限是父节点权限的子集，后台节点（`cell:*`）只能操作授权范围内的节点、卡片和知识，不能批准卡片。网页主人端（`owner`）与外部主代理（`agent`）在控制面上的操作权限完全对等，身份只用于记录操作来源。

- 控制面没有鉴权。服务默认监听 `127.0.0.1`，Host 与跨站检查拦截浏览器里的网页。`NG_DESK_HOST` 绑定非回环地址时，能访问该端口的人都可完全控制工作台和在本机运行的分身；`NG_DESK_ALLOWED_HOSTS` 限定接受的 Host 名称，不识别来访者。
- `cell:*` 身份规则约束后台节点经内核发出的工具调用。本机任何进程，包括节点在 shell 里执行的命令，都能访问回环控制面，这一层没有凭据阻隔。

**`P-SAFE-5`**　节点代次隔离已关闭工作。人工决定同时核对所见事项修订号及关联文稿版本。冲突保留人工稿，后台补充进入可查看的参考区。

**`P-SAFE-6`**　停滞检测检查执行、外部触发、有实际答复来源的内部等待、相关人工决定和停靠状态。无关待办不能掩盖失联；同原因但等待集合不同的事件独立处理。

**`P-SAFE-7`**　暂停通过祖先链生效。后台回收检查实例、进程身份和整个进程组。宿主休眠恢复、时钟回拨和进程重启后，只允许一个执行者持有有效认领。
