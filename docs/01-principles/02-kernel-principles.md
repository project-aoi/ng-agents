# 内核与编排

**`P-KERN-1`**　持久项目保存结构化上下文、共享文稿和工作笔记。分身的最大子代深度为零，回合结束后保持待命；父项目通过 inspect_cell 拉取交付。

**`P-KERN-2`**　异步工作使用有身份的信封。勾选、保存、推迟、撤销及重新打开通过同一领域命令和数据库事务处理。输入与回执的可见性必须一致。

**`P-KERN-3`**　监听先读当前事实，再决定完成、重新检查或求助。定时任务可使用脚本。持续重试、重复事件或时钟修正不得丢掉已接收输入。

**`P-KERN-4`**　脚本处理确定性检查。简单判断使用轻量命令行档位，复杂执行使用相应模型。稳定前缀保存角色契约，笔记、花名册及追加输入由动态部分承载。

**`P-KERN-5`**　长交付物写入共享且带版本的 Artifact，节点间传摘要和引用。压缩保留任务、最近进展和资料指针。编辑时传所见版本，冲突时保留双方内容。

**`P-KERN-6`**　独立终审在独立上下文中依据需求、工作树与测试判定。项目协调器检查所有在途任务、人工动作及验收条件后才能结项。
