# 人机分工与文稿核对

对比报告的第一份源码已就绪，第二份需要主人提供。项目先派分身处理可读材料，同时在待我处理列出需要人的动作。主人修改初稿后，后台补充仍可在参考区核对。

## 行为约定

**`INV-UC03-01`**　仅部分缺材料时，其他可执行分支继续推进。

**`INV-UC03-02`**　主人的动作归属项目，完成后通知对应项目，包括批准方案中列出的人工步骤。个人行动补绑项目后，由该项目接收办结回执。

**`INV-UC03-03`**　保存文稿检查版本。后台更新与人工稿冲突时保留两份；工作台显示远端最新版供比较。同项目的分身可以接力编辑，无关项目不能覆盖文稿。绑定立项卡的方案仅允许发起节点和主人修改。

**`INV-UC03-04`**　阶段交付按主人批准的计划推进。调整计划时收回已经废弃的动作。

**`INV-UC03-05`**　新卡到达不抢焦点。决定始终基于当前卡片和明确审阅过的文稿。直接打开事项链接时优先显示该卡，方案仍有未保存修改时阻止确认。
